# Changelog налоговых ставок — TaxBG Pro

## Процедура обновления при изменении закона

### Шаг 1 — Получить сигнал об изменении
Подписаться на:
- **Държавен вестник RSS**: https://dv.parliament.bg
  (все новые законы и поправки — публикуются там первыми)
- **НАП новости**: https://nap.bg/page?id=3
  (налоговые изменения с официальными разъяснениями)
- **Министерство на труда**: https://mlsp.government.bg
  (МРЗ — объявляется в ноябре-декабре на следующий год)

Ключевые даты для мониторинга:
- **Декабрь каждого года** → проверить МРЗ, МинОсиг, МаксОсиг,
  ставки КСО (меняются с 1 января)
- **Каждый квартал** → проверить ДДС ставку для хотелей (9%)
- **При любом изменении ЗКПО/ЗДДФЛ/ЗДДС** → проверить
  соответствующую ставку немедленно

### Шаг 2 — Верифицировать по первоисточнику
Открыть `officialUrl` из `TAX_AUDIT_TABLE` (taxRatesAudit.ts).
Убедиться в:
- Номере ДВ бр. и дате публикации
- Дате вступления в силу (≠ дата публикации!)
- Точном значении (не округлять самостоятельно)

### Шаг 3 — Обновить в коде (два файла)

**ФАЙЛ 1: `src/constants/tax-rates-2026.ts`**
```
value: НОВОЕ_ЗНАЧЕНИЕ,
effectiveFrom: 'ДАТА_ВСТУПЛЕНИЯ_В_СИЛУ',
```

**ФАЙЛ 2: `src/lib/taxRatesAudit.ts`** — в `TAX_AUDIT_TABLE`:
```
currentValue: <выражение с новым значением>,
expectedValue: НОВОЕ_ЗНАЧЕНИЕ,
lastVerified: 'СЕГОДНЯШНЯЯ_ДАТА',
nextReview: 'СЛЕДУЮЩАЯ_ДАТА_ПРОВЕРКИ',
```

### Шаг 4 — Добавить запись в этот файл (ниже)

```
| ДАТА       | Ставка           | Старое | Новое | ДВ бр.    | Вступает |
```

### Шаг 5 — Собрать и проверить
```bash
npm run build
```
Убедиться, что аудит не показывает `mismatch`.

## Примечания

- Все суммы в EUR с 01.01.2026 (Закон за въвеждане на еврото в Република България)
- Курс фиксирован: 1 EUR = 1.95583 BGN (необратимо)
- Минимальный уставной капитал ООД/ЕООД: 1 EUR (Търговски закон, изм. 2025)
- ДДС ставка 9% для хотелей и ресторанов — временная мера, введена в 2020;
  периодически продлевается. Проверять каждый квартал.
